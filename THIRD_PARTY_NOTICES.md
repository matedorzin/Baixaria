# Avisos de componentes de terceiros

O instalador inclui executáveis de terceiros baixados durante a compilação:

- **yt-dlp**: versão oficial para Windows publicada em [yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp).
- **FFmpeg e ffprobe**: build Essentials para Windows publicada por [Gyan](https://www.gyan.dev/ffmpeg/builds/). Essa build é GPLv3. A página de builds informa a versão, o checksum e o commit do código-fonte correspondentes ao pacote.
- **Deno**: executável oficial para Windows x64 publicado em [denoland/deno](https://github.com/denoland/deno).

O workflow de release verifica os checksums disponíveis antes de usar os executáveis. Consulte os projetos de origem para os textos completos de licença e código-fonte de cada versão distribuída.
